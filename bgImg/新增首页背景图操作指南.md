# 新增首页背景图操作指南

首页背景图使用两套同编号的 WebP 文件：

```text
full/001.webp       # 1920x1080 完整图
preview/001.webp    # 480x270 低清占位图
```

页面先显示低清占位图，完整图加载并解码完成后再淡入。新增图片时，必须同时生成完整图和占位图，并更新代码中的图片总数。

## 1. 准备源图

源图可以是 JPG、JPEG、PNG 或 WebP，宽高比不限。转换时会保持原始宽高比并居中裁剪为 16:9，不会拉伸图片。

建议选择分辨率不低于 1920x1080 的图片，避免放大后画质下降。

## 2. 打开项目目录

在 PowerShell 中进入项目根目录：

```powershell
Set-Location "D:\TenSoFlow\Code\Blog\tensoflower"
```

确认 FFmpeg 可用：

```powershell
ffmpeg -version
ffprobe -version
```

如果系统无法识别 `ffmpeg`，请将下方脚本中的 `$ffmpeg` 和 `$ffprobe` 改成它们的实际绝对路径。

## 3. 生成下一组图片

只需要修改 `$sourceImage`，将它指向需要新增的源图，然后执行整段脚本：

```powershell
$sourceImage = "D:\Pictures\new-background.jpg"
$backgroundRoot = "D:\TenSoFlow\Code\Blog\tensoflower\src\.vuepress\public\bgImg"
$ffmpeg = "ffmpeg"
$ffprobe = "ffprobe"

if (-not (Test-Path -LiteralPath $sourceImage -PathType Leaf)) {
  throw "找不到源图片：$sourceImage"
}

$fullDir = Join-Path $backgroundRoot "full"
$previewDir = Join-Path $backgroundRoot "preview"
$fullFiles = Get-ChildItem -LiteralPath $fullDir -Filter "*.webp" -File
$previewFiles = Get-ChildItem -LiteralPath $previewDir -Filter "*.webp" -File

if ($fullFiles.Count -ne $previewFiles.Count) {
  throw "full 和 preview 的图片数量不一致，请先检查现有文件"
}

$nextNumber = $fullFiles.Count + 1
$imageNumber = "{0:D3}" -f $nextNumber
$fullOutput = Join-Path $fullDir "$imageNumber.webp"
$previewOutput = Join-Path $previewDir "$imageNumber.webp"

if ((Test-Path -LiteralPath $fullOutput) -or (Test-Path -LiteralPath $previewOutput)) {
  throw "编号 $imageNumber 已存在，停止执行以避免覆盖文件"
}

& $ffmpeg -hide_banner -loglevel error -y `
  -i $sourceImage `
  -vf "scale=1920:1080:force_original_aspect_ratio=increase,crop=1920:1080" `
  -c:v libwebp -quality 80 -compression_level 6 -preset photo -an `
  $fullOutput

if ($LASTEXITCODE -ne 0) {
  throw "完整图生成失败"
}

& $ffmpeg -hide_banner -loglevel error -y `
  -i $sourceImage `
  -vf "scale=480:270:force_original_aspect_ratio=increase,crop=480:270" `
  -c:v libwebp -quality 30 -compression_level 6 -preset photo -an `
  $previewOutput

if ($LASTEXITCODE -ne 0) {
  throw "占位图生成失败"
}

$fullSize = & $ffprobe -v error -select_streams v:0 `
  -show_entries stream=width,height -of csv=s=x:p=0 $fullOutput
$previewSize = & $ffprobe -v error -select_streams v:0 `
  -show_entries stream=width,height -of csv=s=x:p=0 $previewOutput

if ($fullSize -ne "1920x1080") {
  throw "完整图尺寸错误：$fullSize"
}

if ($previewSize -ne "480x270") {
  throw "占位图尺寸错误：$previewSize"
}

Write-Host "新增成功：$imageNumber"
Write-Host "完整图：$fullOutput"
Write-Host "占位图：$previewOutput"
```

当前已有 `001-080`，所以上述脚本下一次会自动生成：

```text
full/081.webp
preview/081.webp
```

## 4. 更新图片总数

生成图片后，需要同步修改以下两个文件。两个数字必须相同。

### `src/.vuepress/config.ts`

找到：

```ts
const candidates = Array.from({ length: 80 }, (_, index) => index + 1);
```

新增 `081` 后改成：

```ts
const candidates = Array.from({ length: 81 }, (_, index) => index + 1);
```

### `src/.vuepress/client.ts`

找到：

```ts
const homeBgImages: HomeBackground[] = Array.from({ length: 80 }, (_, index) => index + 1)
```

新增 `081` 后改成：

```ts
const homeBgImages: HomeBackground[] = Array.from({ length: 81 }, (_, index) => index + 1)
```

以后每新增一张图片，就将两个文件中的总数同时加一。例如新增 `082` 后，两处都改成 `82`。

## 5. 检查编号和配对

运行以下命令，确认完整图和占位图数量相同、编号一一对应：

```powershell
$backgroundRoot = "D:\TenSoFlow\Code\Blog\tensoflower\src\.vuepress\public\bgImg"
$full = (Get-ChildItem (Join-Path $backgroundRoot "full") -Filter "*.webp" | Sort-Object Name).BaseName
$preview = (Get-ChildItem (Join-Path $backgroundRoot "preview") -Filter "*.webp" | Sort-Object Name).BaseName
$differences = @(Compare-Object $full $preview)

Write-Host "完整图数量：$($full.Count)"
Write-Host "占位图数量：$($preview.Count)"
Write-Host "编号差异数量：$($differences.Count)"

if ($differences.Count -gt 0) {
  $differences
  throw "完整图和占位图编号不一致"
}
```

正确结果中的三个关键值应为：

```text
完整图数量：相同
占位图数量：相同
编号差异数量：0
```

## 6. 构建验证

项目当前应使用 Node.js 20.20.1 或兼容版本。执行：

```powershell
npm run build
```

构建成功后，生成文件位于：

```text
src/.vuepress/dist/bgImg/full/
src/.vuepress/dist/bgImg/preview/
```

最后打开首页并多刷新几次，确认新增图片能够被随机选中，且显示过程为“低清占位图 -> 完整图淡入”。

## 注意事项

- 文件名必须使用三位编号，例如 `081.webp`，不能写成 `81.webp`。
- `full` 和 `preview` 中必须存在同编号文件。
- 编号必须连续，不能跳号。
- 不要只复制源图到目录中，页面只读取 WebP 文件。
- 不要直接覆盖已有编号，除非明确要替换该背景图。
- 替换已有背景图时不需要修改图片总数，但必须同时替换完整图和占位图。
